# Video Game Sales Analysis

## Project Overview
This project focuses on analyzing video game sales data to understand sales performance across different platforms, genres, publishers, and regions. The analysis helps identify top-selling games, popular genres, successful platforms, and regional sales patterns.

## Objectives
- Identify top-selling games based on global sales.
- Calculate total global sales across all years.
- Analyze sales performance across different platforms.
- Identify popular genres and their sales trends.
- Find top-performing publishers according to genre.
- Compare sales across different regions.

## Analysis Performed
**Data Preparation:** Checked missing values, data types, and dataset information. Handled missing values where required.

**Exploratory Data Analysis:** Generated descriptive statistics using `describe()`, calculated total and average sales using `groupby()`, and visualized data distributions using histograms and box plots. Outliers were identified through box plots but were not removed because they represent actual sales variations in the video game industry.

**Top-Selling Games:** Identified games with the highest global sales and calculated total sales across all years.

**Platform Analysis:** Compared global sales across platforms and examined their performance over time.

**Genre Analysis:** Analyzed popular genres and compared their sales across platforms and regions.

**Publisher Analysis:** Identified top-performing publishers based on global sales across different genres.

**Regional Sales Analysis:** Compared sales across North America, Europe, Japan, and other regions.

## Tools & Technologies
Python is used for data analysis with Pandas for data manipulation, Matplotlib and Seaborn for data visualization and Jupyter Notebook as the development environment.

## Conclusion
This project helped me understand how video game sales vary across different platforms, genres, publishers, and regions. Through data analysis and visualization, I explored sales patterns, identified popular games, and gained insights into the factors influencing video game sales performance.
